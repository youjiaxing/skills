# 商品选购调查：待验证经验

记录日期：2026-11-11。来源：门口电池监控选购会话及其真实复盘。

## 状态与用途

用户明确要求持久保留本次经验，以便在新会话购买其他商品时继续验证。本文件是仓库内的持久经验记录，不放在可清理的临时目录，也不被 Git 忽略；保存不表示这些做法已经验证有效，也不表示已同意创建 Skill。下一次结合新任务判断下列做法是否适用，无需复制本次全部调查步骤。

新会话不会仅因文件存在就自动读取。用户可提供本文件路径并说明：“参考这份待验证经验，帮我选购……；任务结束后结合实际反馈更新它。”其他工作区或设备需要能访问该文件或收到其内容。

## 本次实际暴露的问题

- 比较不足便将单款定为首选并请求确认；用户连续要求增加候选、横向比较和统一排序。
- 相近型号主要以编号展示，用户难以区分；中文简称、联网版本、单摄或双摄、单机或套装后来才补齐。
- 用户转而关注长期免费云录像后，调查多次停在“未确认”，需要用户推动才能继续核对重点候选。
- 商品页要求登录后就向用户索要截图；用户要求自行寻找后，实际从其他渠道取得了精确型号手册。
- 一些来源只支持历史促销、销售索引或同系列宣传，不能证明当前商品套餐权益；App 广告、现场覆盖与续航仍缺实测。

这些事实证明本次执行有不足，不证明新增 Skill 就能解决，也不证明下列方法已适用于其他商品。

## 下一次可尝试的做法

1. **比较后再收敛。** 一般选购提供有实质差异的可行候选，按当前需求解释排序与取舍；用户只查某款时先回答该款。候选数量随有效差异决定，不固定数量、不为扩充清单重复列同类产品。
2. **先分清具体商品。** 用易读名称配完整型号，保留影响选择的版本、销售地区、单机或套装差异。仅将双方同口径且有证据的参数作为优劣依据，缺项保留未知。
3. **优先查会改变选择的事实。** 区分设备能力、当前价格、赠送服务、实际体验。权益记录对应商品或套餐、赠送期限与使用限制；历史活动、搜索摘要和同系列资料用于发现线索，再追决定性来源。
4. **入口受阻后换来源。** 在正常访问和既有授权范围内，寻找品牌资料、说明书、其他销售渠道或可用 App；不反复撞同一登录或验证限制。可自行取得的材料继续调查；确需用户参与时，说明已经尝试的渠道和具体剩余缺口。
5. **让证据决定结论强度。** “未找到”不等于“不支持”，同系列宣传不等于精确型号规格；限定证据适用的字段、版本和时间。解决关键缺口后更新推荐，继续搜索已不影响选择时停止。
6. **给出实际选择依据。** 说明现在更推荐谁、代价是什么、哪些未知会改变推荐。用户调整优先级时同步调整比较重点；展示图表也应让核心购买判断容易找到。

## 下一次如何评价

任务结束时记录用户实际认可、不认可或要求调整的做法，以及结果是否仍需用户反复推动。特别观察：候选是否够用、关键事实是否主动查清、未知是否表达准确、结论是否帮助选择、调查成本是否值得。

允许删改本记录中的假设，不以 Agent 自评“按步骤执行完毕”作为效果证明。不预先锁定候选数量、来源顺序、工具、表格字段或展示形式。

本次的品牌排除、预算、安装环境和充电要求仅属于原任务；新任务重新判断适用条件。产品型号、价格和服务条款需按新任务重新核验。
