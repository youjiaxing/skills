# 状态对外表述

对用户报告状态时按证据分层，避免把其中一个阶段说成整条链路完成：

| 已确认证据 | 可以说 | 不能据此说 |
| --- | --- | --- |
| Codex `completed` 且有非空最终文本 | “Codex 已产出最终回答” | “飞书已收到” |
| 回复 `confirmed` 且有消息 ID | “回答已送达飞书” | “后续一定可以引用追问” |
| `followUp.state:ready` | “这条消息可以引用追问到该会话” | “当前会话仍在运行” |
| `unknown`、`unconfirmed` 或缺回执 | “结果尚未确认，保留原编号核查” | “没有发送”或自动重发 |

处理表情只表示受理、完成或需关注，不能替代 Codex、回复和来源登记证据。客户端实际可读性还需在目标设备检查，服务端成功回执不等于视觉验收。
