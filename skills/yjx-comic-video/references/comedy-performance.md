# 喜剧表演：关键姿势、反应与停顿

设计包袱、颜艺切换、听者反应或停顿时读取。既有制作经验与外部候选方法分开使用；外部内容的出处和验证范围见[来源](sources.md)。

## 已有制作经验

- 镜头停留须承担交代关系、等待回答或消化信息的任务。静止保持可用；无信息的干等应调整起声/切点，把时间留给包袱成立后的听者反应，不靠批量眨眼、推镜或气泡弹跳补救。具体时长按原声/阅读量确定。
- 有限动画按关键姿势的意义和保持时间设计。省略动作可切听者，让动作在画外完成，回切核对合理终态；跨景别同时延续表情强度与目光。素材拼接细节见[分镜与连戏](shot-continuity.md)。
- 讲话、嘴态与表情是不同层次。连续讲解可保持姿势；话锋、理解或情绪改变时，安排实际绘稿、目光或听者反应，不以持续张闭嘴代替表演。

## 候选方法：按原声组织一个喜剧回合

借鉴 `anticipation-payoff`、`rhythm-pacing`、`staging-mastery` 及 HyperFrames 的角色参考。它们提供设计方法，尚未证明整组采用能提高本项目成片质量或降低 Agent 成本；沿用已认可演出，新增用法先在授权的代表段验证。

1. **准备**：找出观众开始理解包袱的词或动作。可以吸气、看一眼、短暂停顿，也可以刻意不给准备以形成突袭；不强制每个动作先反向运动。
2. **爆发**：确定重音对应的关键姿势、镜头和特效。先保证表情可读，再考虑集中线、爆字、短冲击或闪帧；无需同时启用所有效果。
3. **保持**：让观众读懂结果。台词继续时用同一头部/角度的配套嘴态；静默时收口，听者反应与主要爆点错开，避免多人同时抢焦点。
4. **收住**：说明这一回合怎样进入下一句：回稳、泄气、切听者或留白。收势不自动等于缓动回到默认脸。

每一拍写入现有表演表的时间点、素材与保持区间，不另建第二套剧情真相。时点依据原配音和阅读量，固定比例、音乐拍点和统一秒数均不作为对白硬标准。

## 颜艺切换的取舍

正常表情过渡可用准备和收势；日式喜剧允许有意的硬切、冲击帧和突然定格。核对的是观众能否理解变化，以及脸部锚点、画风和空间是否连续。上游“表情永不直接跳变”不作为这里的禁令。

需要重绘整个头形时，可用明确反应切镜并持续这一回合，再切对手；同句反复跳回不匹配的旧头会显得跳位。身体弹性、手持晃动和轮廓抖动属于风格选择，不能为增加“动画感”批量施加。

完成条件：准备、落点、保持、收住都能在实际片段中找到；连续观看时信息和笑点成立。技术检查与静帧只能支持各自覆盖的结论，不代替用户对节奏与自然度的判断。
