# 生活信息查询

帮助用户查询去哪玩、去哪吃以及相关事实。地点、活动、价格、营业、交通和来源核验属于本 Skill；用户明确要求时，也可交付单个查询地点的双平台入口或将该地点收藏到账户。将多个地点排成有顺序的日程、制作或调整正式旅行攻略、生成旅行地图与维护行程属于 `yjx-travel-planning`。本 Skill 可以为旅行规划提供地点证据，但不自行组织日程或维护攻略。按本轮需求使用宿主已有工具，浏览器优先内置浏览器：先按类型选定，再新建标签页使用，标签页为空属正常状态；某个入口报错时换回内置浏览器核对，再决定是否退到外部浏览器。新服务安装、账号接入和配置修改需另有授权。

## 1. 确定本轮约束

确定本轮是找地点、比较、核价还是核验已有资料。若用户目标是规划或更新有顺序的旅行行程/正式攻略，转交 `yjx-travel-planning`，本 Skill 只为其提供地点与事实查询。采用对话中相关的城市/片区、日期时段、交通、预算和已定安排，只补问会改变选择的缺项；周边查询通常用地标即可。将相对日期落到用户时区的具体日期。亲子任务再考虑年龄、推车、午睡，不从旧会话默认家庭画像或精确住址。

保留排除条件及已选、已预订事项；收到纠正或新信息时，修正受影响的推荐和取舍，说明影响，保留仍成立的已定条件。已付款或已预订的项目作为硬约束，付款或预订确认后不再为其寻找或比较同类替代项，已保存的候选记录仍保留；用户已选定但未付款的项目默认沿用，同类候选继续保留为备选，该选定项目仍可被新信息推翻。确认本次要解决的选择后再检索，避免把周边找店扩成完整旅行。

## 2. 按问题选来源并核查

需要外部检索时，读 [来源选择与分支核查](references/sources.md)，选当前字段需要的入口。用户要求看、解析或补充推荐视频时，执行其中的 [视频读取完成标准](references/sources.md#视频读取完成标准)。厦门查询同时读 [厦门入口与读取经验](references/xiamen.md)；其他城市找同类发布主体。检查或选择官方接口时，再读 [工具接入范围](references/tools.md)。

先发现候选，再进入决定性原文。核对具体地点、分店和设施身份；公园与园内独立设施分开。搜索摘要、评分、热门榜、精华标签只帮助发现。会改变选择的字段已取得证据或明确缺口后停止扩搜，不要求每次查遍所有平台。

**核验时效：**区分发布日期、实际到访日期、适用日期和本次查询日期。动态规则须适用于目标日期；设施/路况优先近期、同季节实探，旧文仅用于不依赖现状的经验。“最新”标题或今天抓取不证明内容新；未来只有常规规则时，说明预计依据。

公共交通地图算路不证明目标日期可乘：逐段核对试运行规则、目标日期班次及换乘；关键环节未确认时，将整条方案标为有条件，并说明不能使用时的已核备选或缺口。

当期取消/封闭公告通常优先于常规介绍，官方页面同样核版本及适用范围。同源转载算一条证据；解决会改变选择的冲突，未解则降低推荐强度并说明限制。比较优劣时，只将双方均已核实且口径一致的差异作为依据；单方缺项记为未知，资料更多不代表方案更优。

优先使用已有 MCP、官方接口或网页；原生桌面应用的 UI 自动化只在没有可用接口时使用，浏览器访问网页仍走网页路径。对同一受限平台合并请求、控制连续操作频率；遇到登录、验证码、风控或设备限制，停止重复尝试并说明障碍。可使用已有授权且正常可用的其他入口或来源，不绕过验证、迁移 Cookie 或另装抓取工具。工具存在、来源可读、读到本次内容与事实核实分别判断。

当用户指定的平台关键内容只在原生 App 可见，或网页在本轮已确认受限时，且已授权 iPhone 链路可用，转用 [`yjx-iphone-app-ops`](../yjx-iphone-app-ops/SKILL.md) 读取 App 页面；大众点评查询使用其 `dianping-search` CLI；需要门牌/营业摘要或分享入口时读其原生内容规则，小红书先用 `xiaohongshu-search` 发现卡片，再核原帖；优先读取 accessibility/OCR 输出 JSON，并按 [大众点评结构化观察](references/sources.md#大众点评结构化观察) 转为待核验候选，只有状态要求时才读取截图。来源评估、时效核验、事实判断和推荐仍按本 Skill 执行。没有可用设备时继续网页/其他来源路径，不为查询新建登录态或绕过验证。

## 3. 交付地点和依据

简洁给出推荐理由、取舍、相关位置/预算、原文链接及影响选择的未知。事实与适配推断分开，候选与用户定案分开；资料不足就给有条件候选，不为凑数降低质量，不把“未找到”说成“不存在”。

**交付具体景点/门店时，执行 [iPhone 双平台地点链接](references/place-links.md)**：取得标识、生成入口、核对目标并处理缺口，其中提供可复用脚本。按实际验证层级说明结果。

用户明确要求收藏单个查询地点时，执行 [高德单地点收藏](references/place-links.md#高德单地点收藏)；收藏不等于加入旅行地图或生成行程。

交付前确认：推荐身份清楚、符合已知约束、决定性依据适用；价格和路线口径明确，链接缺口与影响选择的未知已说明；涉及保存时已回读核验。部分完成按实际状态交付。

## 4. 真实任务复盘

每次实质任务完成后，可简短提醒真实复盘，不强制或重复催促。查询完成复盘来源、工具与核验；出行体验以用户实际反馈为据。

提炼可复用的入口、查询词、字段陷阱、失败处理和用户纠正，保留证据日期及适用边界。区分来源可读、事实核实、实际体验；读取成功或推荐获采纳不等于来源优质。单篇错误先影响该内容，反复低质再降级入口。提出最小改进，获授权后更新 Skill；个人资料仅按本任务授权保存。

技能维护采用静态审阅、引用/打包检查和新增脚本功能测试；收益通过真实使用观察，不创建或运行模拟会话行为测试。
