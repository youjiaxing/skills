# 结构编辑

用于跨段去重和整篇重组。入口已经规定依据与含义保护，本参考只补充结构判断方法。分析保留在内部，除非用户要求审阅或编辑说明。

## 读出实际主线

先确认全文实际在回答什么，再与用户本次目的比较。开篇承诺、标题和正文应一致；各自都写得通顺却回答不同问题，仍需要调整结构。

长文在内部为每段或区域记一句话：它陈述哪个主点，为前后内容提供什么。区分答案、证据、背景、定义、原因、条件、反例、行动、导航与换言复述；只记录足以支持当前编辑的程度，不要求给短答建立整套台账。

沿这些简短记录阅读，寻找：

- 两处承担同一作用，却没有新增的理解或判断依据；一个观点换多套比喻、例子或框架也属于候选。
- 结论埋在过程记录后，或读者尚无所需定义、对象与条件就遇到细节。
- 相邻段落之间缺少真实关系，指代无法唯一对应；删掉连接词并不能修复这类断裂。
- 一个段落混入不同主线；某项内容出现后没有承接；标题承诺与正文不符。
- 开头预告、正文展开、段末回收和全文总结反复列同一组观点。

## 按删除损失选择动作

编辑候选须指出具体位置、作用冲突及修改后由哪里承载必要信息。合并相关意思时汇集独立细节；移动时保留前提与引用。

| 动作 | 适用情况 |
| --- | --- |
| 删除 | 空话、无作用的预告或重述，纯修辞例子没有新增作用 |
| 合并 | 同一主点散落多处，各有需要保留的细节 |
| 移动或拆分 | 有用内容放错位置，或一段承担不同问题 |
| 压缩 | 独立含义需要保留，但表达比理解所需更长 |
| 保留 | 背景、过渡、摘要、实例或重复标签有明确理解、导航或查证作用 |
| 指出缺口 | 缺少材料才能补齐关系，或原稿存在无法自行裁决的矛盾 |

同主题不等于可删除：多个独立试验、约束或选项可能共同支撑一项结论。它们应分组或集中展示，不能只留“最强的一项”。概念相同但适用条件不同，也不能压成无条件结论。

## 检查改稿的阅读路径

只读标题，确认略读者能找到关键问题、判断与行动；再顺读正文，确认新概念有锚点、推理没有跳步。查找型参考不必改成线性故事，操作指南也不必塞入全部背景。

逐项回看改前各段的实质作用：是被完整承接、获准裁剪，还是意外丢失。按入口完成双向含义核对；达到本次目的即可停止，不用继续多轮改写来追求某种统一文风。
