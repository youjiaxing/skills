# 手机画面适配

本参考只适配已选择隔离观察的手机截图。按名称发现已安装的 `yjx-iphone-app-ops`，从其安装位置读取 `references/operations.md` 的“视觉手势”共用契约；缺少依赖时报告缺口，不猜测相邻目录。直接读图与隔离观察都遵守该契约。设备命令、独占与锁、未决请求恢复、动作授权及后置验证继续由原控制代理负责；视觉 worker 只离线读取文件，不创建 session、查询页面、截图或执行动作。

## 图像与观察身份

控制代理按原技能生成视觉观察 JSON 和新截图，再准备模型输入。把下列必要背景交给 worker：原观察的 `bundleId`、`readAt`、`imageSha256`、截图路径、`viewport`，以及图片准备清单的输入路径、输入 SHA 和像素宽高。原图 `imageSha256` 是设备动作凭据，压缩输入 SHA 仅标识 worker 看到的副本，两者不可互换。

派发时附上共用契约中本次观察需要的定位规则。worker 返回文字观察、疑点及必要的目标定位；原控制代理将结果绑定到源观察，按共用契约检查全幅定位、观察时效和当前画面。

## 回传与验收

worker 回传时可能已经过期；重新观察及允许复用定位的条件由共用契约规定，不改写旧时间戳，也不用输入副本 SHA 替代原图 SHA。新画面需要重新确认时，按当前问题合批观察，不能沿用旧定位。

本适配遵循共用契约的视觉坐标实际链路验收要求，并按[取图入口](capture.md)核对工具输出与父会话记录中的隔离效果；未验证的路径保持未验收。
