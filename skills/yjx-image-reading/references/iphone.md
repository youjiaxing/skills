# 手机画面适配

本参考只改变模型读取截图的入口。设备命令、独占与锁、未决请求恢复、动作授权及后置验证继续由 `yjx-iphone-app-ops` 和原控制代理负责；视觉 worker 只离线读取文件，不创建 session、查询页面、截图或执行动作。

## 图像与观察身份

控制代理按原技能生成视觉观察 JSON 和新截图，再准备模型输入。把下列必要背景交给 worker：原观察的 `bundleId`、`readAt`、`imageSha256`、截图路径、`viewport`，以及图片准备清单的输入路径、输入 SHA 和像素宽高。原图 `imageSha256` 是设备动作凭据，压缩输入 SHA 仅标识 worker 看到的副本，两者不可互换。

worker 返回文字观察和疑点；需要定位时返回唯一目标标签及截图完整范围内的归一化区域 `{x, y, width, height}`，值在 0–1。使用未裁剪、方向不变的全幅输入；若为阅读细节另附原像素裁剪，定位仍以全幅原图为基准。`viewport` 是 AX 点尺寸，不是图片像素尺寸，不能直接把截图像素坐标当作设备点击坐标。

## 动作前确认

原控制代理核对目标身份与作用是否在任务授权内，优先当前原生语义或已确认的 DOM 目标。需要视觉手势时，使用原技能的 `target` 和 `gesture` 命令，不直接发送裸坐标。

- 观察仍有效时，按既有唯一标签、归一化区域、30 秒有效期及当前画面 SHA 校验执行。
- worker 返回时观察已过期，实际重新 `observe`，获得新的截图和 JSON；只有 `bundleId`、`viewport` 与原图 SHA 均与已识读画面相同时，才将已核目标标注到这份新观察，再由现有 `gesture` 重新验证。不是改写旧 JSON 的时间戳，也不用输入副本 SHA 替代原图 SHA。
- 新画面或视口不一致时，旧定位失效，重新确认必要画面；不能确认则明确受阻，不自动点击或无限重试。前后画面比较可以一次交给新的只读视觉任务。
- 存在 unknown/reset-required 时，先按原恢复协议处理；重新观察、截图或 finally 清理也不能发重叠命令。动作发送后仍须验证任务的后置条件，视觉意见本身不构成执行授权或成功证明。

启用视觉坐标路径前，分别验收正常、观察过期和画面变化的实际链路；未通过时不能宣告该入口可用。离线协议测试不等于真机通过。
