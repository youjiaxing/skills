# 维护：yjx-scheduled-tasks

运行规则以 [SKILL.md](SKILL.md) 为准；本文件用于评审和演进，不作为第二套执行步骤。

## 设计依据与边界

2026-11-09 根据用户在多个项目、不同电脑上的实际反馈创建：任务完整指令反复被内联进调度器，难以随项目维护；重要指令丢失后难以重建。用户确认首版覆盖 Agent 宿主任务的创建、修改、提示词整理及恢复，允许模型按需调用。它是顶层 `skills/` 中可跨项目安装的通用技能，不是本仓库内部维护入口。

持久化对象是难重建的任务意图与指令，不是调度配置。用户明确排除版本化周期和环境清单；复制这些内容会形成多真源。已有技能、脚本、项目说明优先复用，任务独有内容才落到所属仓库；简单短任务允许内联。无新调度器、调度备份服务、固定 Git 提交发布策略或跨机器同步机制。

写作依赖原版 `writing-for-agents`，不派生 `yjx-writing-for-agents`。上游已有上下文指针、单一事实源、信息层次与拆分原则；本技能落实的是调度操作中的组织方法，不将这些原则重新声明为独有发明，也不宣称派生自某个上游调度技能。

独立方案审查发现：整理共享入口可能影响其它任务或手动调用。已将已知调用方和共享范围核对纳入正文；任务独有要求通过参数或专属入口表达，范围外行为修改需对应授权。创建、修改或恢复的请求不等于立即运行任务业务，配置成功与业务成功须分别报告。

## 验证与后续维护

首版采用文档工作流，无自有脚本和测试。验证使用静态审阅、一致性、YAML 与包装链接核对；不创建或运行模拟会话、提示词行为测试或对应测试文件。方案独立审查不等于已运行所有宿主的定时任务；实际宿主与执行环境兼容性须按具体任务核实。

2026-11-09 首版验证：frontmatter 与 `agents/openai.yaml` YAML 解析通过，按需调用设置一致；顶层 skill 包可被目录发现，正文、维护记录及 README 中的 15 个本地链接存在，差异空白检查通过。README 与编辑前工作区比对，仅新增本技能入口。未执行全局安装、配置真实定时任务、试跑任务业务或提交推送；这些静态结果不证明模型实际遵循流程。

复查时重点看真实任务是否仍复制既有真源、遗漏持久化独有指令、擅自改变无关调度设置、误改共享调用行为，或把读取/配置成功当成实际运行验收。只有出现真实独立分支和足够维护收益时才增加专项参考或代码，不预设平台适配目录和模板体系。
