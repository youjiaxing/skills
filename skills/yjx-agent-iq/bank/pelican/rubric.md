# 鹈鹕题证据与评分

本文件只供考官和只读视觉观察者使用，不进入被测方题面。每项记录 `pass | fail | review`、理由和证据文件；缺证据保持 `review`。

1. **原文能运行**：原始 HTML 完整，可直接运行；浏览器无控制台错误、未请求外部资源。静态扫描只提供线索。预览副本调整过高度或样式时，另存副本、变更说明和哈希；副本成功不能证明原文通过。
2. **鹈鹕可辨认**：画面呈现长喙、喉囊/下颌、身体和腿，整体可辨认为鹈鹕。
3. **自行车结构**：画面有两个轮子、车架、车把、车座和脚踏；若绘制链条，检查是否合理连接。
4. **坐姿合理**：身体位于车座上方，腿能接触脚踏，翅膀或前肢与车把合理连接。
5. **动画协调**：观察完整代表性周期中的关键相位，车轮和脚踏转动，腿脚保持接触，主体没有明显跳动或脱离。

固定在可复现的时间点取帧，记录时间基准、主要周期、帧时间和对应路径。例如周期为 T 时覆盖 `0、T/4、T/2、3T/4` 并按需要补查相位间接触；多条不同周期的关键动画须覆盖相互关系。不能把两张未知时间、近似同相位的截图当作协调证明。时序未知、关键相位缺失或看不清时保持 `review`。

通过已安装的 `yjx-image-reading` 取得隔离视觉观察；其结果只支持已观察到的帧。调用方保留原文运行记录、网络/控制台证据、帧文件及逐条评估，实际观察结果与推断分别标注。

全部五项均有证据且为 `pass` 才通过。任何错误记 `fail`，任何缺证据/未知记 `review`。若提示加入了评分细则，结果只能标为该提示条件下的样例，不能计作严格原题通过。用户尚未观看确认时，最终视觉评价标“待用户体验”。
