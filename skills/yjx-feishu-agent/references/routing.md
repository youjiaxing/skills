# 公共群的引用路由

同一机器人可接收多个 Codex 会话的推送。所有已授权接入的群默认支持引用路由，无需逐群开启：白名单用户直接引用消息并 @机器人时，优先交给该消息登记的来源会话。引用消息没有来源记录或来源明确为空时，若群有默认 `threadId` 就回退到该会话，并在回复正文说明来源未登记、本次已回退；没有默认会话仍拒绝，不猜测其他会话。未引用时沿用默认会话。机器人加入某群不等于该群已获接入授权；群与用户白名单仍须明确配置。

现有 `quoteRouting:true` 保持兼容，省略该字段同样启用；仅显式 `quoteRouting:false` 可停用某群的引用路由：引用消息一律沿用默认会话，不读取来源账本，不显示回退说明。关闭引用路由但没有默认会话时配置仍可加载，收到消息后按 `DEFAULT_UNCONFIGURED` 阻断。不提供新建、停止或管理其他会话的远程指令。

## 来源与投递

出站 send/update 显式提供 `sourceThreadId`，由已授权的本机调用方取自实际 Codex 会话标识。它不是从消息正文、标题、最近聊天或群默认会话推断的，也不是授予群成员访问所有本机会话的入口。群用户白名单和明确 @ 条件保持不变。

来源映射按应用、群、飞书消息 ID 隔离，存于仓库外 `message-routes-v1/<app hash>/<chat hash>.json`。同一卡片由最近一次成功发送或更新它的会话负责；源字段与投递请求一起保存，成功后发布映射。未携带来源的旧投递继续支持 status/去重，但不能引用路由；不扫描历史猜测来源、不改写旧请求指纹或重新发送。需要历史登记时先在本机核对原请求及真实来源，当前命令不提供任意消息 ID 导入。

更新前先设置路由 pending；远端成功而本地记账未完成、提交结果未知或来源存档损坏时，新引用保持待核查，不使用旧来源或默认会话兜底。`pending` 优先于空来源。只有整个条目缺失或 `sourceThreadId:null` 属于可回退的未登记来源；字段缺失、空串、非法 UUID 或结构损坏仍阻断。已有成功 acknowledgement 可通过 `outbound.mjs reconcile` 修复本地投递和来源；此过程不发消息。旧记录没有来源时无法由恢复命令补猜。明确未提交的更新可恢复原映射，原失败证据保留。

## 受理与继续追问

直接引用的消息 ID 是唯一选路依据，不沿祖先查找另一会话：某张卡片由 A 更新为 B 后，新引用卡片交给 B；直接引用此前 A 的回复仍交给 A。话题客户端若仅提供根消息 ID，就只能按该根消息登记的来源选择，不声称能辨认未提供的最近回复。

入站受理与出站更新共用群级锁；受理时读取并持久保存目标、`routeMode` 与来源消息 ID 后释放锁，后续卡片更新不改变已经受理的目标。锁忙、冲突、待核查或结构损坏时不提交；有默认会话的未登记来源按群绑定回退。重复事件按原入站编号去重；重启不重放队列或未知请求。

成功回复记录实际飞书回复 ID 和本次实际使用的会话，供继续引用；群绑定回退后的回复再次被引用时，因此成为正常来源路由。若回复已送达但来源记账失败，保留回执和未决记录，不重新发送回复。本机原有群消息按需查询接口保留，自动近期群历史已取消，见 [上下文](messages.md)。

## 归档与不可用

仅有效来源命中的引用请求允许自动解归档；群绑定回退和普通默认请求沿用默认会话的归档阻断规则。先取得原会话锁，检查目标明确为 archived，持久记录恢复意图，调用 `thread/unarchive`；返回 ID 必须一致，再用 `thread/read` 确认活动状态，才提交这次追问。响应丢失、接口不支持、仍归档或读取失败均不提交、不自动重放、不新建或换会话。恢复后保留活动状态，不自动重新归档。默认绑定请求仍沿用原归档阻断规则。

这是接收器内部的限定能力，不新增通用 agent CLI 的自动恢复开关。实际 Desktop 专属工具、会话锁及审批限制沿用 [Codex 接入](codex.md)。

## 接入与回滚

已有授权群升级后自动使用全局规则，默认会话不变。新增群仍须先核对群和允许用户；接收器须停止，bind 共用应用锁。指定 `--thread DEFAULT_UUID` 可设置用户选定的默认会话；省略它只授权该群引用已登记的消息，不选择默认目标。

```text
node skills/yjx-feishu-agent/scripts/receiver.mjs stop
node skills/yjx-feishu-agent/scripts/feishu.mjs bind --chat oc_GROUP --user ou_ALLOWED_USER
node skills/yjx-feishu-agent/scripts/receiver.mjs start
```

所有命令支持 `--state-dir PATH`。已绑定群需要明确停用时，停服后运行 `bindings.mjs quote-routing --chat oc_GROUP --enabled false`，命令保存配置前后快照并保留消息来源、投递和入站记录；没有默认会话时拒绝停用。切换前检查当前未决请求，不通过回滚删除账本或重放事件。验收包括不同群的默认引用能力、未登记来源回退、无默认群的提示、待核查与损坏阻断、A/B 来源、卡片更新换来源、回退回复继续引用、归档恢复、跨群引用内容读取、引用路由记录隔离和重启去重。协议/状态测试通过不等于已完成实际飞书到 Desktop 的往返验收。
