# 视频生成与图生视频提示词规范

设计文生视频、图生视频（I2V）、首尾帧锁定或编写/优化视频模型提示词时读取。本规范聚焦通用的动作表达、防漂移约束与模型能力边界；实际可用模型、调用授权、中转契约及计费上限以所属私有项目文档为准，未经项目授权不自动发起生成。

## 1. 图生视频（I2V）提示词四原则

- **只写变化量，不重述静态锚点**：输入图已经确定主体外貌、构图、服饰与色调；提示词专注描写**要发生什么动作、物理互动与镜头运动**，不堆砌原图已有的长段静态描写。
- **单镜头单目标与 `Subtle > Dramatic`**：每条提示词只承载一个场景、一条核心动作与一个情绪节拍；用轻微、自然的动作动词代替大幅度剧烈形变描述，降低肢体扭曲与闪烁概率。
- **加 `STILLNESS LOCK` 显式静止锁**：对仅局部需要动的镜头，在提示词中明确标出保持静止的部位与元素（例如背景保持静止、头发不飘、非动作手部与双肩保持原位），防止模型给静止室内硬加吹风摇发或无意义摆手。
- **不把接口参数写进提示词并按动作选短时长**：不在提示词正文里书写模型名、分辨率、画幅或接口字段（除非特定模型模板强制要求时间轴分段）；按完成核心动作的最短自然时长设置外部参数，不默认直接拉满模型上限。

## 2. 首尾帧与多图参考用法区分

- **首尾同图循环/微动（`image == last_frame`）**：仅用于已有明确物理或剧情支点（如端杯轻抿再放回、抬手示意）的短往返反应动作；注意控制单动作周期节奏（避免周期过长拖出均匀“慢动作”感），不要在缺乏动作动机的纯对白静止镜头里硬塞首尾同图制造“活背景”。
- **首尾异图过渡（`image != last_frame`）**：用于状态 A 演进到状态 B 的过渡镜头；仅描述从起态到终态的连贯动作与力学变化，采用前先按项目小样流程实测过渡自然度。
- **多参考图绑定角色与道具（R2V）**：不锁死首帧而只保持主体或物品外观时，显式写清每张参考图在镜头中承担的角色、服饰或道具身份，避免模型混叠特征。

## 3. 主流模型适用与避坑边界

以下为基于[来源记录](sources.md)整理的外部参考与通用倾向，具体到项目选用仍以当前实测与授权为准：

- **Grok 视频系列（如 `grok-imagine-video-1.5`）**：提示词开头前句权重高，先写景别/风格与主体核心动作再补氛围与声音；适合短片与参考图条件生成，**不适合**长时间连续多场变化或强依赖确定性随机种子的精细复现。
- **图生微动与写实/自然物理倾向（如 `Wan` / `Seedance` / `Kling`）**：`Wan` 与 `Seedance` 偏重自然物理与角色/首尾帧连续控制，适合将静态场景或角色锚定图做出克制微动；若使用跨模型通用提示词，始终保持单主运动方向与显式 `STILLNESS LOCK`。

## 4. 拼接与小样核验门禁

- 跨镜头复用底板或把视频动作插镜接回静态立绘序列前，先核对相邻帧的色温一致性及四嘴态/闭眼图层匹配，避免明显跳色调或脸部偏移（多人与空间连戏另见[分镜与连戏](shot-continuity.md)）。
- 新写法或跨姿势/长过渡首次启用前，先用最小低分辨率短样验证静止区是否乱动、首尾衔接与主体五官是否漂移，确认通过后再超分或扩量合入正片。
