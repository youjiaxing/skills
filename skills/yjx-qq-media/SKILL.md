# QQ 消息图片

用户已授权读取的 QQ 消息含图片时，使用 `scripts/qq_image.py`。调用方负责选择群、日期和消息，并从自己的只读消息源取得原始图片字段；本能力不遍历聊天、不管理账号、不发送消息。

1. 将明确选定消息的图片 protobuf 字段传给 `resources_from_blob(blob)`。它按同一图片元素关联文件 MD5 与原图 URL，避免把多图、表情或邻近消息混在一起。返回空列表时报告该消息的资源字段不受支持，保留来源。
2. 对每个资源调用 `fetch(resource, private_output_directory)`。已有可校验原图先复用；URL 中没有 rkey 时，只读检查已运行 QQ 进程中的图片下载参数。参数仅在内存中使用，不打印或落盘。仅向 QQ 官方图片域名下载，禁止重定向。
3. 完成条件是文件为支持的图片、大小不超过 10 MB，且 MD5 与消息字段一致。下载失败、超时或校验不符时停止并保留来源，不以文件名或 HTTP 成功状态替代校验。
4. 使用宿主图片查看工具实际看图，再描述内容；需要投递时交给已有投递工具上传本地文件。带下载参数的 URL 不是长期附件链接。

接口返回 `path`、`md5` 和 `cached`；下载参数不进入输出。纯资源解析与下载使用 Python 标准库；从 QQ 进程补齐下载参数需要 64 位 Windows 和已登录的 QQNT。它只请求查询和读取进程内存权限，不注入、不附加调试器、不更改客户端或数据库。其他平台或无可用参数时明确报错；不要通过陌生下载代理转发私有资源。

本模块由调用任务通过 `importlib.util.spec_from_file_location` 按配置定位，不依赖固定盘符或用户目录。QQ群、身份、任务快照、图片和下载流水保存在调用方的私人运行目录。
