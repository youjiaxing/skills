# 画面取帧与画质门禁

决定是否取图、从解码帧截取软件演示画面以及验收裁剪和画质时读取。画面必须基于实际查看结果记录；“文件已保存”不等于已完成视觉核对。

## 取帧策略与准入检查

建立证据骨架后，依据内容类型选择画面策略；缺少文字证据时，画面也可作为最初取证路径：

| 视频类型 | 典型信号 | 标准模式画面策略 |
| --- | --- | --- |
| 纯演讲、访谈、播客 | 主要由连续口述构成，缺少终端或幻灯片 | 必须保留开场身份确立或现场重要实物（如主讲人/嘉宾同框、白板板书、演示硬件/书籍）；纯口述段不堆砌人像，也不强制生成图表 |
| PPT、课程幻灯片 | 图表、公式、流程图或板书承载论证 | 截取页面切换及承载结论的关键页 |
| 软件操作、代码演示 | 界面、终端、编辑器或状态变化是教学对象 | 在动作发生处、画面切换处和结论处取帧，覆盖前后状态变化与关键文字 |
| 不确定 | 现有证据不足以判断画面是否必要 | 检查高价值段画面以确认类型和取证缺口 |

每张候选图入课前先回答：**“学习者看这张图能多知道什么？”** 同时核对五项准入条件：

1. 字幕或音频是否已完整表达该主张；
2. 画面是否提供了文字无法表达的信息（代码、命令、配置、文件路径、错误信息、终端输出、UI 按钮/菜单/状态、图表公式或操作前后对比）；
3. 学习者是否需要看到它才能复现操作、理解结构或核对状态；
4. 已有图片是否已经覆盖同一主张（同一张图可复用以支持多个主张，不重复取图）；
5. 该图能否减少误解或补足前提。

只保留带来新增学习信息的画面；重复字幕、重复已有截图或仅增加无信息增量人像的候选予以丢弃（`disposition: "discard"`）。图片数量不由视频时长决定，也不按固定秒数等间隔采样；当所有关键视觉主张已覆盖且新增画面不再提供信息时立即停止。

## 截图边界与裁剪验收

- **区分视频帧与教学界面**：视频本身是来源证据；视频内出现的编辑器、终端、浏览器或 GitHub 页面属于教学对象，予以保留，不因“像网页”而误删。
- **剥离外部非视频外壳**：来源页面或播放器外层的导航栏、地址栏、书签栏、推荐栏、弹幕栏、播放列表、广告和站点标题不属于教学对象，不进入最终课程图。直接从视频流抽取的清晰解码帧天然不含此类外壳。
- **原生构图顺其自然**：讲者摄像头和原片内置字幕属于原生视频画面；只要不遮挡核心命令、代码或关键信息，自然保留，不为抠除头像或原片字幕反复微调裁剪参数。仅在严重遮挡核心内容或需局部放大时做一次粗粒度裁剪。
- **软件演示必须导出原始解码帧**：网页播放器常将 1080P 画面缩放在 600–900 CSS 像素容器中，直接对页面视图截图裁剪会导致终端和编辑器文字模糊。标准流程：**定位目标时刻的清晰视频源/解码帧 → 取得接近 `videoWidth × videoHeight` 的原始帧 → 按教学对象边界生成聚焦裁剪图 → 在最终嵌入尺寸下视觉复核文字清晰可读**。
- **双层产物**：软件演示通常保留“原始帧 + 聚焦裁剪”两层产物；原始帧用于时间和来源核验，聚焦版用于 Markdown 和 Notion（原始解码帧本身无无关外壳时也可直接作为聚焦图）。
- **边界完整性**：裁剪保留完整命令、文件路径、按钮名称、错误信息和图表关系；若完整信息与去壳无法兼得，宁可保留更大范围并注明，不靠猜测补全被裁断文字。
- **脱敏与降级**：最终嵌入前脱敏画面中的密码、Token、API Key、私钥与含密码连接串。无法稳定嵌入或权限不允许复制时，报告具体限制并保留时间点与文字观察描述作为降级交付。

## 分辨率、帧率与记录字段

- **清晰度与帧率分开选择**：软件演示默认请求并优先使用实际可达的 **1080P**；仅在确认 1080P 不可达时回退到 **720P**，低于 720P 不得作为最终课程图。选定分辨率后优先选择实际帧率更高的流；取图前记录请求档位、实际下发档位、实际帧率与 `videoWidth × videoHeight`，不把菜单或 `accept_quality` 列表当成实际下发档位。回退与登录判断遵守 [访问门禁与登录态判定](access-gates.md)。
- **7 项画面能力技术字段**：软件演示在底稿或能力记录中登记 `capture_surface`、`selected_quality`、`selected_frame_rate`、`decoded_frame_size`、`rendered_player_size`、`device_pixel_ratio` 和 `final_image_size`。
- **物理与可读验收门槛**：最终图有效文字高度低于约 12 像素、解码帧高度低于 720 像素，或实际档位低于已声明可达档位时判为不合格，改用更高画质源重取（或按门禁处理登录），不用放大插值或旧版低清图交付。视觉复核按**最终嵌入尺寸**检查终端、编辑器和文档截图是否能辨认命令、路径、状态和标签，不以“原视频也不清”放行。
- **证据与索引记录**：Candidate/kept 画面记录所需的 `visual_claim`、`knowledge_segment`、`information_added`、`why_text_evidence_is_insufficient`、`duplicate_of_existing_image`、`disposition`（`"keep"` / `"discard"`）和 `keep_or_discard_reason` 字段定义与校验标准见 [证据记录与自动审核](evidence-audit.md)。底稿中严格区分“画面显示”与“根据画面推断”，模糊或被裁切文字标为低置信度。`visual_coverage.embedded_files` 只登记最终嵌入图。
