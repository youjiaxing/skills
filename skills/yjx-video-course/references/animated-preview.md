# 学前动画导览

用户要求学前动画导览、交互预览或指定 `--导览 动画` 时读取。目标是让没看过原视频的读者先建立内容概览，再细读文字正文；原视频用于回看和核对疑问。文字正文只解释视频实际提供的内容；参数和操作步骤仅在视频给出且适用于当前内容时保留，不为导览补齐视频外背景或实践任务。

## 外部技能：检查、缺失即安装、读取

`bang-motion` 是运动编排依赖，不复制其整套指引到本仓库。进入动画制作前完成以下步骤；安装由该工作流自动执行，不把安装命令留给用户代办，也不为已授权的缺失安装重复询问。

1. **检查当前环境。** 先查当前 Agent 的可用技能清单；未列出时，再检查该宿主实际使用的项目级和用户级技能目录。例如 Codex 检查项目 `.agents/skills`、`.codex/skills`，以及 `${CODEX_HOME:-$HOME/.codex}/skills` 和 `~/.agents/skills`；其他宿主按其真实发现目录检查。仅名称出现不算就绪，实际读取 `bang-motion/SKILL.md`，确认本次所需的引用与 starter 可读。已有可用版本直接复用，不自动升级或覆盖。
2. **缺失时自动安装。** 仅安装下面指定的上游技能，范围限定为当前 Agent 的用户级技能目录，不安装整仓库其他技能，不改当前项目配置。优先使用当前环境的 `skill-installer`；读取它的实际位置和用法后调用安装脚本，不硬编码某台机器的工具路径。安装参数是 `--repo bangtutorial/bang-motion --ref c1aa65e921c970d858705fcb4a53a8294d1a4131 --path . --name bang-motion`。Codex 安装器默认使用 `${CODEX_HOME:-$HOME/.codex}/skills`；配置了其他目标时沿用真实目标。
3. **没有安装器时使用 Git + Skills CLI。** CLI 把 URL 中的提交 SHA 当作分支克隆，不能直接用固定提交的 `tree/<SHA>` URL 安装。先在当前系统创建本次任务的临时目录并取出固定提交，再从本地目录安装。下面是 POSIX shell 示例；其他宿主使用等价的临时目录和参数传递方式，并将 `--agent` 换成 CLI 实际支持的当前宿主标识。先用 `npx --yes skills --help` 核对，不省略 Agent 选择而扩大到所有宿主。

   ```bash
   motion_stage_dir=$(mktemp -d)
   git -C "$motion_stage_dir" init
   git -C "$motion_stage_dir" remote add origin https://github.com/bangtutorial/bang-motion.git
   git -C "$motion_stage_dir" fetch --depth 1 origin c1aa65e921c970d858705fcb4a53a8294d1a4131
   git -C "$motion_stage_dir" checkout --detach FETCH_HEAD
   npx --yes skills add "$motion_stage_dir" --skill bang-motion --agent codex --global --yes --copy
   ```

   每步成功后才执行下一步。`--copy` 使安装结果不依赖临时源目录；完成文件回读后清理本次创建的临时目录。记录真实上游与提交，不把 CLI 记录的临时路径当作来源。

4. **安装后验证并继续。** 记录实际安装目录、来源与版本/提交；从该目录重新读取 `SKILL.md`，并读取本次需要的 `references/anti-ppt.md`、`references/explainer.md` 与对应 starter。成功退出或 CLI 显示安装成功不能替代这些文件的实际读取。如果宿主技能清单要到下一回合才刷新，本回合直接读取已安装指引作为参考继续，不声称发现列表已刷新。

新安装的基线为上游提交 `c1aa65e921c970d858705fcb4a53a8294d1a4131`（2026-10-15 核对，MIT）；[固定版本源码](https://github.com/bangtutorial/bang-motion/tree/c1aa65e921c970d858705fcb4a53a8294d1a4131)。更新这个基线时重新核对相关指引、许可与适配要求。不要把已验证旧版本的结果推广到任意最新版本。

安装不可用时记录具体障碍，例如网络、缺少安装工具、写权限或同名损坏目录；保留已有目录，不强制覆盖，不静默换来源或伪装为已使用 `bang-motion`。停止动画分支，继续保存已完成的文字课程，报告动画导览未完成。正常外部访问与权限边界仍适用。

## 本工作流对上游指引的适配

本节适配优先于上游默认流程。学习目标和交付范围明确时，自主完成风格简报、分镜与实现，无需为上游的风格或分镜批准环节额外请求确认。

- 学习目标、证据与用户选择由本技能决定。`bang-motion` 的宣传片、配音、导出视频、隐藏播放器等默认值不能扩大请求范围。
- 默认制作网页动画，不要求生成视频、图片或配音。可以自动循环播放、使用 CDN；用户要求离线交付时再改为内联或本地资源。尊重减少动态效果设置，并保留显式播放入口。
- 保留可见的播放/暂停、重播与进度定位；空格能在播放与暂停之间反复切换，包括焦点停在进度条或播放器按钮时。长按不重复切换；编辑文字与输入法组合输入时不抢占空格。
- 以桌面与实际嵌入窗口验证为主，不专门增加手机适配工作，除非用户要求。
- 引用或改编上游代码时保留其 MIT 许可与来源；CDN 运行依赖在交付中说明，加载失败要有可理解的提示。

## 从可信课程到分镜

先读取已审核正文及其本集证据，选择最能建立整体理解的少量关系：问题与结果、结构、过程、因果、对比或依赖。通常以约 1–2 分钟为目标，按实际概念复杂度调整；详细操作留给文字课程。

先规划每个讲解节拍要让读者看见的变化，再编写动画。讲解清楚什么、画面如何变化、前后对象如何对应、当前注意点分别是什么，应能从分镜中看出。已有充分需求时自主完成设计；探索新动画语言时，可先做一段代表性样片验证效果。

- **用动作解释关系。** 同一对象或同一世界持续存在；状态、位置、连接或形态的变化随新信息发生。仅让文字和方框依次淡入，不能算过程演示。
- **逐步引导注意。** 每一步只引入少量新信息，尚未讲到的内容先隐藏，已讲内容按需保留为背景；用短讲解句或图内标签配合画面，不把正文缩写后同时铺开。
- **保持因果和对应。** 先显示前提与动作，再呈现结果；跨场景继续使用的对象应可辨认，不能要求读者自行猜测两幅图的对应关系。镜头用于聚焦与揭示关系，不机械地对每句话缩放。
- **结构服务课程。** 问题解决类可采用“提出问题 → 常见做法与问题 → 正确做法 → 回顾与悬念”；其他课程按其知识组织，不固定页数、时长、配色或动画模板。提出问题时保留未知，后续再揭晓解法。
- **守住证据。** 动画中的事实与因果绑定本集证据；为解释机制创造的数值和例子标为示意，不把动画的容量条、运动速度或视觉比例伪装成实测结论。导览与正文发生冲突时回到原始证据校正，不靠免责声明保留矛盾。

## 保存与 Notion 交付

输出为 HTML，采用项目约定的路径和文件名；无约定时与对应 `course.md` 放在同一目录，命名为 `preview.html`。保留本地文件，即使最终交付到 Notion。结尾提供文字教程入口，原视频作为进一步核对的次要入口。正文入口应实际可读，不能把正文下载链接说成已提供网页阅读体验；上传到 Notion 时，检查入口是否仍可访问，不能沿用仅本地可用的相对路径。

用户选择 Notion 交付时，沿用主流程的目标页核对、正文审核与写入校验，复用对应课程记录，默认按“动画导览 → 文字教程 → 原视频入口”编排。按当前连接器的实际能力执行：

1. **优先直接上传 HTML 并嵌入。** 当前连接器的 `create-attachment` 支持小型 UTF-8 HTML 的 `content` 上传；先核对工具支持范围、内容大小及工作区文件上限。使用上传结果中的 `file-upload://` 来源，按连接器文档保存为 `<embed>`，而非代码块或普通文件块。读取当前 Notion Markdown 规范及工具返回的嵌入语法，不假定其他连接器也具备此能力。动画依赖 CDN 时，说明播放需要联网。
2. **回读与播放分别验证。** 写入后回读对应课程页，确认 HTML 已成为持久的嵌入块，且页面顺序与正文入口正确。在 Notion 实际嵌入窗口验证画面、播放、暂停与恢复及进度定位；上传成功、页面回读成功都不能替代播放验证。浏览器受限时记录“已上传嵌入，播放待验证”；用户实际确认的结果可以作为验证证据，并注明由用户确认。
3. **能力不足时再考虑托管。** 当前连接器不支持 HTML 嵌入或实测无法播放时，保留本地 HTML 并报告具体限制；已有获授权的托管方案时，可改用允许嵌入的网页地址。没有部署授权时不自行发布，也不把“尚未托管”视为直接上传嵌入路线的缺口。

## 分开验证事实与体验

1. **事实与阅读链路。** 对照正文和原始证据检查核心判断、示意标注、术语首次出现与总结对应；确认文字入口指向正确课程。
2. **动画与控制。** 在可用浏览器中亲自播放，并检查关键时刻与转场；验证暂停后能恢复、回退与拖动能重现正确状态、手动定位终帧不会误触循环、重播与自然循环正确。检查控件聚焦后空格仍能切换，持久对象、运动路径和镜头没有压住文字或裁掉教学主体。
3. **首次读者视角复核。** 请未参与方案形成的只读子代理优先实际操作网页，审查注意力、衔接与控制，而不只核对文章内容；无法运行浏览器时明确静态复核的局限，不能声称已感受动画。

记录实际验证范围。静态文档、链接与包装校验不能证明动画易懂；禁止为技能提示词生成模拟对话或模型行为评测。浏览器不可用时保留产物并报告体验尚未验证，不宣称完整交付。
