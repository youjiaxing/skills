# 个人全局提示词

本目录保存可以公开、跨机器复用，并且需要在多个 Agent 中保持一致的个人规则。这些文件是提示词源文件；`scripts/link-skills.mjs` 只负责发现并安装 `skills/` 下的 Skill，本目录内容由后续的独立同步步骤处理。

## 目录

- [`shared/communication.md`](shared/communication.md)：沟通、命名与交付格式。
- [`shared/subagents.md`](shared/subagents.md)：子代理职责、调度、审查与执行边界。

`targets/` 目录只在出现真实平台差异时按需创建，文件名采用 `targets/<agent>.md`。

## 组合顺序

面向某个平台生成最终提示词时，按以下顺序组合：

1. `shared/communication.md`
2. `shared/subagents.md`
3. `targets/<agent>.md`（如果存在）

目标平台文件只记录平台差异。共享规则以 `shared/` 中的文件为唯一真源；目标平台文件需要改写共享规则时，应明确指出被替代的规则及原因。

本目录只负责保存源文件；激活到某个 Agent 的全局配置由后续的独立同步脚本完成。

## 公开边界

可以公开的稳定规则放在本目录。身份信息、公司内部规则、凭据、机器专有路径及其他私密内容放在仓库根目录的 `prompts.local/`；该目录已被 Git 忽略。需要跨机器同步私密内容时，应使用独立的私有仓库。

## 维护原则

- 每条规则只保留一个权威位置，其他文件通过链接引用。
- 优先描述期望行为；只有无法用正向表述替代的硬性边界才使用禁止性措辞。
- 新建目标平台文件前先确认规则确实无法共享，避免复制整份共享提示词。
- 修改后检查规则是否仍然明确、可执行，并且没有与其他文件重复或冲突。
